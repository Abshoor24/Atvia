# Panduan Aset Foto Produk ATVIA

Silakan simpan file foto produk resolusi tinggi Anda di folder ini:

1. **Hero Lineup Banner**:
   - Nama file: `hero-lineup.webp` (atau `.jpg` / `.png`)
   - Rasio: `16:10` atau `16:13`
   - Ukuran ideal: Minimal lebar 2000px (contoh: 2400 x 1500 px)
   - Latar: Studio gelap / showroom netral konsisten

2. **Foto Produk Individual** (Rasio 4:5):
   - `shampoo-mobil.webp` (800 x 1000 px)
   - `semir-ban.webp` (800 x 1000 px)
   - `pembersih-ruangan.webp` (800 x 1000 px)
   - `remover.webp` (800 x 1000 px)
   - `compound.webp` (800 x 1000 px)
   - Format yang direkomendasikan: WebP atau AVIF dengan kompresi kualitas 85-90%.
